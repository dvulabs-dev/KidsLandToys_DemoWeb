PRODUCT PHOTOS
==============
Every product shows /images/products/<product-id>.jpg automatically (no code change needed).
To use the shop's own photo, just replace the file with the same name
(landscape 4:3, about 1200x900 px, under 300 KB is ideal).

The current photos are free-to-use stock photos from Pexels (Pexels License: free for commercial
use, attribution not required) standing in for the shop's real stock. They show similar products,
and some show visible brand names, so replace them with the shop's own photos before launch.
